# Document Intelligence RAG System

An AI-powered system that uses Retrieval-Augmented Generation (RAG) to retrieve information from documents and generate relevant answers.

## Requirements

- Python 3.11
- Git
- Visual Studio Code (recommended)

## Installation

### 1. Install Python

Download Python 3.11 from the official website:

https://www.python.org/downloads/

Verify the installation:

```powershell
python --version
```

### 2. Clone the Repository

```powershell
git clone https://github.com/adamelhabian/document-intelligence-rag-system.git
cd document-intelligence-rag-system
```

### 3. Create a Virtual Environment

```powershell
python -m venv .venv
```

### 4. Activate the Virtual Environment

**Windows PowerShell:**

```powershell
.\.venv\Scripts\Activate.ps1
```

**Windows Command Prompt (CMD):**

```cmd
.venv\Scripts\activate.bat
```

Once activated, `(.venv)` should appear at the beginning of your terminal prompt.
